# محاضرات عملي الحشرات التفاعلية

كلية التربية للعلوم الصرفة / علوم الحياة، المرحلة الثالثة.

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | الصفحة الرئيسية، فيها روابط المحاضرات التسع |
| `lab-01.html` … `lab-09.html` | محاضرة لكل مختبر. كل ملف مستقل وما يحتاج أي ملف ثاني |
| `scripts/` | نصوص التعليق الصوتي لكل مختبر |
| `audio/` | (اختياري) ملفات الصوت، تضيفها بعد ما تولّدها |

## النشر على GitHub Pages

1. سوِّ مستودع جديد وارفع بيه كل الملفات.
2. من **Settings → Pages** اختار **Deploy from a branch**، والفرع `main`، والمجلد `/ (root)`.
3. بعد دقيقة أو دقيقتين يصير الرابط بهذا الشكل: `https://اسم-الحساب.github.io/اسم-المستودع/`

الباركود بكل صفحة يتولّد تلقائياً من رابطها، فما تحتاج تعدّل أي شي.

## الصوت داخل الصفحات (اختياري)

سوِّ مجلد اسمه `audio` وحط بيه ملفات الصوت بنفس رموز المقاطع، مثل `audio/lab1_s01.mp3`. الصفحة تشغّل كل مقطع ويا مشهده تلقائياً، وتضبط طول المشهد على طول الصوت.
